# منصة تشغيل 3,6T

تطبيق محلي يعمل بقاعدة معاملات SQLite وواجهة عربية RTL. يشمل حسابات تجريبية، خدمات قابلة للتهيئة، طلبات وموافقات ومرفقات وتدقيق، ومشاريع ومهام، ومسارات محلية للمبيعات والمشتريات والإجازات والتوظيف والاستوديو والدفتر المالي. نطاق المشروع الكامل 220 متطلبًا؛ سجل التتبع يميز الأجزاء المنفذة عن العمل المتبقي.

## التشغيل

استخدم Node 24.21.0 (الإصدار الذي اختُبر محليًا) وnpm. لا توجد اعتماديات تشغيل خارجية.

```sh
npm ci --ignore-scripts --offline
npm run setup
node scripts/expand-demo.mjs
node scripts/expand-services.mjs
npm start
```

expand-services يضيف 13 إدارة مقترحة و72 خدمة طلب؛ التفاصيل في docs/implementation/COMPANY-WIDE-PROMPT.md. التوسعة تضيف حسابات وتقويمًا ونطاق توظيف وتصاريح مالية مصطنعة دون استحقاقات مفترضة. شغّل setup مرة واحدة في نسخة جديدة فقط. النسخة الحالية مهيأة؛ ابدأ بـnpm start إذا كانت المعاينة متوقفة. يرفض setup الكتابة فوق المستخدمين. يحفظ كلمة مرور عشوائية لحسابات الاختبار في outputs/local-credentials.txt المستبعد من Git.

افتح http://127.0.0.1:3600. بيانات المعاملات في work/local.sqlite، والمرفقات داخل القاعدة نفسها. الخادم يستمع إلى الجهاز المحلي فقط ويرفض وضع production. لا يوضع خلف وكيل نشر بهذه الإعدادات.

## تجربة المسار

1. employee: أنشئ «طلب دعم تقني»، ثم أضف مرفق TXT/PDF/PNG وقدم الطلب للاعتماد.
2. manager: راجع الطلب ثم اعتمده أو أعده مع السبب.
3. it: استلم المعتمد ثم أكمله مع دليل. الاعتماد وحده لا يغلق التنفيذ.
4. لخدمة الخطاب، يراجع manager ثم hr. يمكن إعادة الطلب وتعديله وتقديم نسخة جديدة مع بقاء السابقة.
5. manager: أنشئ مشروعًا بعضوية employee وأسند مهمة لها معيار قبول. يكملها employee بدليل.
6. admin: هيئ خدمة جديدة من الدليل. لا يملك هذا الحساب حق قراءة معاملات بقية الموظفين لمجرد أنه مسؤول المنصة.

الأدوار والأسماء والإدارات المحلية مصطنعة لا تمثل الهيكل المعتمد للشركة. outsider يختبر مستخدمًا غير مشارك في المعاملة، وexternal يختبر العزل بين كيانين مصطنعين.

## الفحوص

```sh
npm test
npm run check
npm run trace
```

الفحص الحالي يتحقق من صياغة JavaScript وبصمات المصادر وتطابق سجل المتطلبات. ليس بديلًا لفحص أنواع TypeScript أو محلل أمني شامل. ملفات الواجهة تخدم مباشرة دون عملية تجميع. إعداد GitHub Actions مضاف للفحوص فقط، ولم يُرفع أو يُنفذ على GitHub.
