# تجربة منصة 3,6T

افتح http://127.0.0.1:3600. هذه نسخة محلية ببيانات مصطنعة، غير جاهزة لنقل أعمال الشركة.

بيانات الدخول في local-credentials.txt. employee للطلب، manager للمراجعة والمشاريع، it للتنفيذ، hr للإجازات والتوظيف، admin لكتالوج الخدمات، deputy للتفويض، pm لعضوية المشروع. المالية بحسابي finance-preparer وfinance-approver وتصاريح منفصلة؛ الاعتماد الذاتي ممنوع.

أضيفت مسارات المبيعات والمشتريات والإجازات والتوظيف والاستوديو والدفتر المالي. نجح 130 اختبارًا محليًا. سجل المتطلبات: 67 جزئيًا و152 لم يبدأ ومتطلب واحد متعطل، من أصل 220. لا متطلب مقبول كاملًا. التفاصيل ونقطة الاستكمال في حالة-المنصة.md.

لإعادة تشغيل النسخة الحالية: npm start. لا تعِد setup على قاعدتها. حزمة platform-source.zip تستبعد قاعدة البيانات وكلمات المرور والتصميم التاريخي وGit. لتثبيت تجربة جديدة: Node 24.21.0، ثم npm ci --ignore-scripts --offline، ثم npm run setup مرة واحدة، ثم node scripts/expand-demo.mjs، ثم npm start.
