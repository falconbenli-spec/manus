# عقود التكامل وحدود الاتصال

لم يُهيأ اتصال تشغيلي خارجي. ما يلي سجل تحديد عقود مبني على INT01–INT11 الأصلية؛ لا endpoints أو بيانات اعتماد مفترضة. قبل أي موصل، يعتمد المالك حقول المصدر والاتجاه والمعرف الخارجي والنطاق والتسوية.

## INT01 — الهوية المؤسسية

البيانات: حسابات ومجموعات وتفعيل وإيقاف. المالك المقترح: التقنية.

الاتجاه: مزود الهوية → النظام. الربط المقترح: SSO وواجهات معتمدة إن توفرت.

معيار القبول الأصلي: إيقاف موظف ينعكس على الجلسات والوصول.

القيد الأصلي: لا يفترض مزودًا قائمًا؛ يحدد أولًا.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT02 — Zoho People أو المرجع الوظيفي المعتمد

البيانات: الموظفون والحضور والإجازات حسب مالك كل حقل. المالك المقترح: HR.

الاتجاه: حسب ملكية الحقل؛ لا مزامنة دائرية. الربط المقترح: API رسمي أو تصدير محكوم مؤقتًا.

معيار القبول الأصلي: مفاتيح ثابتة وسجل أخطاء ومطابقة أعداد.

القيد الأصلي: استخدام Zoho ورد في سياق العمل؛ الاتصال الحي لم يثبت هنا.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT03 — المرجع المالي الفعلي

البيانات: دليل الحسابات والمراكز والفواتير والسداد. المالك المقترح: المالية.

الاتجاه: المالية مرجع للترحيل الرسمي. الربط المقترح: واجهة موثقة / وسيط / ملفات مصدقة.

معيار القبول الأصلي: تطابق الأرصدة ومعرف المصدر وعدم التكرار.

القيد الأصلي: SAP/Oracle في الكود تسميات وليست إثبات استخدام.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT04 — Asana أو مرجع المهام المعتمد

البيانات: مشاريع ومهام ومرفقات وروابط البريد. المالك المقترح: PMO.

الاتجاه: تحدد ملكية الحالة قبل الربط. الربط المقترح: API/Webhooks حسب الصلاحية.

معيار القبول الأصلي: حدث مكرر لا ينشئ مهمة ثانية.

القيد الأصلي: البدء بتكامل أو إحلال تدريجي لا دفترين متنافسين.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT05 — Gmail والتقويم

البيانات: طلبات ومراسلات ومواعيد ومسودات. المالك المقترح: مالك صندوق البريد.

الاتجاه: قراءة الحد اللازم؛ إرسال بعد اعتماد. الربط المقترح: OAuth محدود النطاق.

معيار القبول الأصلي: مسودة على التسلسل الصحيح بلا إرسال ذاتي.

القيد الأصلي: تأكيد المستلمين والمرفقات قبل الأفعال الخارجية.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT06 — Google Drive أو مستودع الوثائق

البيانات: وثائق وأصول وروابط وإصدارات. المالك المقترح: التقنية / ملاك الوثائق.

الاتجاه: المستودع مرجع الملف؛ النظام مرجع السياق. الربط المقترح: API مع ACL ومراقبة الروابط.

معيار القبول الأصلي: الرابط لا يتجاوز صلاحيات المستودع أو النظام.

القيد الأصلي: لا تنسخ جميع الملفات الحساسة بلا حاجة.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT07 — قنوات الإعلان والتحليلات

الاتجاه: المنصة الإعلانية → التحليلات أولًا. الربط المقترح: واجهات رسمية حسب الملكية والحدود.

معيار القبول الأصلي: مطابقة فترة وعملة ومقياس ومصدر.

القيد الأصلي: لا نشر أو زيادة إنفاق دون موافقات.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT08 — الفوترة الإلكترونية

البيانات: XML ومعرفات واستجابات وأخطاء. المالك المقترح: المالية.

الاتجاه: النظام المالي ↔ المزود/الهيئة. الربط المقترح: ربط مطابق واختبار تهيئة وبيئة.

معيار القبول الأصلي: حالة قبول رسمية مستندة إلى رد محفوظ.

القيد الأصلي: الوحدة المقروءة محاكاة؛ ليست ربطًا حيًا.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT09 — البنك وحماية الأجور

البيانات: ملف دفع وإشعار تنفيذ وتسويات. المالك المقترح: المالية / الرواتب.

الاتجاه: مسير معتمد → جهة رسمية؛ استجابة ← النظام. الربط المقترح: الصيغة والقناة المعتمدتان.

معيار القبول الأصلي: الاعتماد والرفع والقبول والدفع حالات منفصلة.

القيد الأصلي: لا يفترض توفر API لجميع الجهات.

الحالة: غير مهيأ. الحقول التقنية والمعرف الخارجي وتفويض الاتصال لم تعتمد. سياسة الفشل الحالية: حجب الفعل دون إرسال، وعدم اختراع قبول. يُشترط مفتاح حدث ثابت ومعاملة محلية ومراجعة المطابقة قبل تفعيل إعادة المحاولة لدى المزود.

## INT10 — قوى والتأمينات ومقيم ومدد

معيار القبول الأصلي: لا تكتمل المعاملة بلا مرجع نتيجة رسمي.

القيد الأصلي: لا أتمتة تتجاوز التحقق أو المصادقة المطلوبة.

الاتجاه: استرجاع مقيد؛ تنفيذ بشري معتمد. الربط المقترح: بوابة داخلية وسياسات أدوات.

القيد الأصلي: لا إرسال ملفات رواتب أو شكاوى لمزود غير معتمد.
