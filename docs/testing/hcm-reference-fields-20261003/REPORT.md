# تحقق أنواع الإجازات وجهات تعريف الراتب

التاريخ: 4 أكتوبر 2026. النطاق محلي وببيانات مصطنعة، دون إصدار خطاب رسمي أو تغيير بيانات موظف حقيقي.

## ما تحقق

- نموذج الإجازات المحكوم في المنصة يحتفظ بـ17 نوعًا، ويغطي العائلات التسع الظاهرة في نسخة HCM دون استبدال القواعد النظامية الأحدث بقيم النسخة القديمة.
- دليل تعريف الراتب يحتوي 19 بنكًا و74 سفارة و8 جهات حكومية. تشمل هذه الأعداد جميع بنوك HCM التسعة عشر وسفاراته الثلاث والستين، مع إبقاء الجهات الإضافية الموجودة أصلًا في المنصة.
- نموذج `HR-SALARY-CERT` يطلب نوع الجهة أولًا، ثم يعرض قائمة البنك أو السفارة أو الجهة الحكومية بحسب الاختيار، مع مساري «لمن يهمه الأمر» و«جهة أخرى».
- اختبار المسار المتكامل أثبت أن اختيار «البنك السعودي الرقمي» ينتقل بعد الاعتماد إلى سجل الخطاب بالرمز المرجعي `sdb` والاسم الصحيح.

## نتائج التحقق

- اختبارات الرجوع الخاصة بالاعتماد والرواتب والحزمة الجديدة، ومنها ترقية النموذج القديم: 30/30 ناجحة، صفر فشل وصفر تخطٍّ. الدليل: `regression.tap`.
- فحص سجل التتبع بعد تسجيل الدليل: 2/2 ناجح، مع تطابق 220 متطلبًا و22 مجالًا.
- `npm run check`: ناجح؛ 785 وحدة JavaScript، و165 ملف ترحيل، وأعلى ترحيل 204.
- `npm run gate:quick`: سبعة من سبعة؛ ترقية الاحتياطي إلى 204، سلامة `ok`، صفر مخالفة مفاتيح، وسلسلة التدقيق سليمة. بصمة المخطط بقيت `6f57cbe1ae285047…` لأن الترحيلين 203 و204 يضيفان بيانات وإصدار خدمة دون تغيير المخطط.
- تشغيل الحزمة الكاملة قبل تصحيح سجل الدليل: 2,243 من 2,244 ناجحة، صفر تخطٍّ، والفشل الوحيد كان اسم اختبار جديد غير مطابق في سجل التتبع. بعد التصحيح نجح فحص التتبع منفردًا 2/2 ونجحت اختبارات الرجوع 30/30. لم تُعَد الحزمة الكاملة التي استغرقت قرابة خمس ساعات؛ التحقق اللاحق غطى التتبع والملفات المتأثرة وترقية نموذج قاعدة التشغيل.

## الحدود

- اعتماد قالب تعريف الراتب من مالك إجراء الموارد البشرية ما زال قرارًا تشغيليًا مستقلًا؛ لم يُخترع اعتماد ولم يصدر خطاب رسمي.
- الأدلة المرجعية أسماء ورموز محلية. لم يحدث اتصال ببنك أو سفارة أو جهة حكومية.
- النتيجة تحقق تقني للحزمة وليست قبولًا من مالك العملية أو تصريح استخدام إنتاجي.
