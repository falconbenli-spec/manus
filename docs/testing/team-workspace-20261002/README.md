- نتائج بحث مساحة الفريق كانت تفتح مسارًا قديمًا غير مسجل؛ أصبحت تفتح الأداة الصحيحة داخل المساحة، وثُبّت اختبار رجوع.

## ما تثبته الاختبارات

- العضوية محددة النطاق، وإزالتها تمنع القراءة الجديدة وتبقي نسبة الأفعال السابقة.
- المشروع والإدارة لا يُنسخان إلى قاعدة ثانية؛ المساحة تحمل المحتوى التعاوني فقط.
- القائمة والبطاقات تقرآن المهمة نفسها، والإغلاق يحتاج دليلًا، وتعارض الإصدار يمنع الكتابة فوق نقل أحدث.
- ملف منشور كدليل يثبت نسخته وبصمته، ورفع نسخة أحدث لا يغير الدليل.
- منشور المشروع لا يصبح إعلان شركة، والمحادثة لا تصبح موافقة أو قرارًا ماليًا.
- السؤال الدوري المعلن الهوية لا يكتب في جداول Pulse المجهولة.
- البحث لا يكشف عنوان مساحة بعد سحب العضوية، ولا يفهرس نص المحادثة أو bytes الملف.

## الحدود المفتوحة

- ماسح الملفات غير موصول؛ الحالة الصادقة `unavailable`، ولا يسمح التنزيل في بيئة إنتاجية بوصف الملف آمنًا.
- الضيف الخارجي والعميل معطلان حتى اعتماد سياسة وصول مستقلة.
- لا بريد أو Teams أو Basecamp أو إشعار خارجي ضمن هذه الحزمة.
- الاختبارات التقنية لا تمثل قبول مالكي العمليات أو تجربة حمل أو مراجعة اختراق أو جاهزية إنتاج.
