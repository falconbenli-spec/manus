# تحقق دورة المشتريات متعددة البنود — 24 سبتمبر 2026

## النطاق المنفذ

- يقبل طلب الشراء عدة بنود، ولكل بند وصف وكمية ووحدة وهوية ثابتة.
- يسعّر عرض المورد كل بند على حدة، ثم يحفظ أمر الشراء لقطة البنود والأسعار المعتمدة.
- يسجل الاستلام والفاتورة بكميات مستقلة لكل بند، وتتحقق المطابقة الثلاثية من كل بند قبل إنشاء المستحق المحلي.
- تستمر الطلبات القديمة ذات البند الواحد، ويرحّل عرضها السابق إلى سطر سعر واحد دون تغيير رأس العرض أو اختلاق فاعل بشري.
- تعرض الواجهة البنود والأسعار وكميات الاستلام والفاتورة في جداول، مع بقاء كل العمليات محلية ومن دون إرسال أو إصدار فاتورة رسمية أو دفع.

## الضوابط

- يرفض الخادم بند العرض الناقص أو المكرر أو غير التابع للطلب.
- لا يتجاوز مجموع استلامات أي بند كمية الأمر المعتمدة.
- لا تتجاوز الفاتورة سعر بند الأمر مضروبًا في كميته، ولا تصبح مستحقًا إن تجاوزت الكمية المستلمة.
- تبقى رؤوس المستندات حقول توافق للكود القديم، بينما تكون أسطر المستند المصدر الحاكم للكمية والسعر والمطابقة.
- يفصل النظام بين طالب الشراء ومسجل الفاتورة والمطابق وفق الضوابط القائمة.
