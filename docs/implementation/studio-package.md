# حزمة الاستوديو والتسليم الداخلي

الحزمة تحول موجزًا مرتبطًا بمشروع إلى مخرجات نصية ذات نسخ ومراجعات، وسجل أصول بمراجع داخلية وحقوق معلنة. بيان حزمة التسليم يحفظ النسخ والأصول والاستثناءات المستخدمة. لا ينشئ ملفات صور أو فيديو ولا ينزل مراجع خارجية، والدليل النصي إفادة محفوظة وليس ملف ترخيص مثبتًا.

## عقد API

`listStudio(db,u)` يعيد مصفوفة مساحات مأذونة، تضم `id`, `project_id`, `title`, `owner_id`, `reviewer_id`, `status`, `version`, `brief`, `brief_versions`, `outputs`, `assets`, `packages`, `reviews`, `allowed_actions`.

`createStudio(db,u,input)` يقبل `{project_id,title,objective,audience,audience_basis,message,prohibited_messages,kpi,measurement_source,channels,scope,reviewer_id?}`. حالة البداية `draft`، ويحفظ نسخة موجز رقم 1. `audience_basis` يبين الدليل والافتراضات، و`measurement_source` يذكر مصدر القياس وطريقة جمعه دون ادعاء اتصاله. `channels` مصفوفة من القيم: instagram, x, linkedin, tiktok, youtube, website, internal, print, video, event. لا تمثل هذه القيم تصريح نشر.

`studioAction(db,u,id,action,input)` يعيد المساحة المحدّثة. كل إجراء يتطلب `version` من مساحة الاستوديو، مع رفض الحقول الزائدة. الكتابات تتطلب معاملة مفتوحة من المستدعي، وتضم سجل التدقيق داخلها. يربط الخادم GET/POST على `/studio` وPOST على `/studio/:id/:action`، مع `createOnce` لإنشاء HTTP فقط. الاستجابة المعادة عند التكرار تُقرأ بالصلاحية الحالية.

| الإجراء | الحقول بعد version | البوابة |
| --- | --- | --- |
| save_brief | objective, audience, audience_basis, message, prohibited_messages, kpi, measurement_source, channels, scope | المالك؛ draft أو brief_returned. ينشئ نسخة جديدة |
| submit_brief | لا شيء | المالك؛ draft. يثبت النسخة المطلوب مراجعتها |
| approve_brief / return_brief | note | المراجع المعين المستقل؛ brief_pending. الإعادة تحتاج سببًا |
| add_asset | name, internal_reference, rights_holder, rights_basis, rights_evidence, valid_from, valid_until, channels | المالك؛ production. rights_basis واحدة من owned, licensed, consent، والمرجع معرف داخلي من 3 إلى 80 حرفًا لاتينيًا أو رقمًا أو شرطة أو underscore |
| inspect_asset | asset_id, outcome, evidence | المراجع المستقل؛ outcome هي passed أو failed. الفحص إفادة داخلية ثابتة |
| create_output | title, channel, format, dimensions, language, brand_reference, acceptance, content, asset_ids | المالك؛ بعد اعتماد الموجز. asset_ids من سجل المساحة نفسها |
| save_output | output_id مع حقول create_output | المالك؛ المخرج draft أو returned. ينشئ نسخة جديدة |
| submit_output | output_id | المالك؛ المخرج draft |
| approve_output | output_id, note, quality_checks | المراجع؛ المخرج pending. quality_checks كائن حقوله brand, language, claims, accessibility, specification، وكل قيمة passed |
| return_output | output_id, note | المراجع؛ المخرج pending. السبب مرتبط بمعرف النسخة |
| issue_package | output_ids, use_from, use_until, exclusions | المالك؛ المخرجات المختارة معتمدة وأصولها مفحوصة وحقوقها سارية اليوم وطوال المدة وللقنوات المحددة |
| accept_package | package_id, note, evidence | المراجع المستقل؛ بيان حزمة غير مقبول سابقًا. يعيد فحص صلاحية الحقوق الحالية |

التسلسل الرئيسي `draft → brief_pending → production`، والإعادة `brief_returned → draft`. المخرجات لها `draft → pending → approved` أو `returned → draft`. كل حفظ نسخة جديدة، ولا يعدل موجز أو مخرج معتمد. تغيير الموجز بعد اعتماده يحتاج مساحة جديدة في هذه الحزمة. كل مخرج يرتبط بمعرف نسخة الموجز المعتمدة.

## التفويض والنسخ

كل قراءة وفعل يتطلب عضوًا نشطًا في المشروع بدور employee أو manager أو pm داخل الكيان نفسه. admin ممنوع حتى مع إضافة عضوية مباشرة. المراجع الافتراضي منشئ المشروع. منشئ المشروع وحده يستطيع عند الإنشاء تسمية عضو آخر مراجعًا صراحةً، مع حفظ هوية من عيّنه؛ لا يستطيع المالك مراجعة ما أعده. المراجع يفقد القرار عند سحب عضويته أو تعطيله أو تغير دوره المحفوظ. منشئ المشروع يجب أن يبقى عضوًا نشطًا بدور manager أو pm حتى تبقى سلطة التعيين صالحة.

الموجز والمخرجات والأصول والفحوص والقرارات وبيانات الحزم ثابتة على مستوى قاعدة البيانات. يحتفظ بيان التسليم بمعرفات النسخ ومحتواها ومراجع فحص أصولها والاستثناءات المدخلة؛ لا ينتقل إلى النسخة التالية تلقائيًا. تاريخ حقوق الاستخدام يفسّر بيوم الرياض. لا يوجد نشر أو بريد أو شراء حقوق أو إثبات استخدام خارجي.

## التوصيل والتحقق

الترحيل النهائي `app/migrations/009-studio.sql` ثابت بعد الاختبار؛ لم تعدّل الحزمة الترحيلات السابقة أو قاعدة local.sqlite. الواجهة `app/static/studio-ui.mjs` تصدر `studioUI` بعقد الوحدات المشترك. تجلب `/studio` و`/projects` و`/me`. زر إنشاء الموجز يمرر معرف المشروع إلى `form('create', projectId, data)`؛ أفعال العناصر الفرعية تمرر `studioId:childId` وتحوّلها الواجهة إلى endpoint المساحة ومعرف العنصر في body. لا تعتمد نقطة API على صيغة المعرف المركب.

الحقول مهيكلة؛ اختيار القنوات والأصول والمخرجات يتم بحقول مستقلة، وفحوص الجودة تحتاج اختيارًا صريحًا. تحفظ النماذج version ومعرف السجل عند فتحها. لا يوجد حقل نسخة قابل للتحرير أو textarea لإدخال JSON.

نجح `node --test tests/studio.test.mjs` على الترحيل النهائي 009 بنتيجة 16/16، دون فشل أو تخطي، بزمن 747.080875ms. تشمل الاختبارات مخرجين بقناتين، الإعادة واعتماد النسخة، العزل وسحب الدور والعضوية، حقوقًا منتهية أو مستقبلية أو قصيرة المدة أو خارج القناة، فحصًا مفقودًا أو فاشلًا، مخرجًا غير معتمد، التكرار والتدقيق الذري، انتهاء الحق عند 00:30 بالرياض، وعقود الواجهة وإفلات النصوص. نجح `node --check app/static/studio-ui.mjs`.

الفحص العام وتوصيل الخادم وتشغيل المتصفح مسؤولية المنسق. لا تدعي الحزمة اختبار الواجهة في المتصفح قبل هذا التوصيل، أو قبولًا من مالك الإجراء.
