# الدفتر المالي المحلي

الحزمة تغطي أجزاء من FIN-01 وFIN-05 وFIN-06 وFIN-09. لم يُستبدل مرجع الشركة المالي، ولم يُقرأ حساب بنكي أو يُدفع مبلغ أو تصدر فاتورة رسمية. الأرقام والتصاريح ودليل الحسابات في العينة مصطنعة بعملة SAR.

ينشئ المعد قيدًا من سطرين إلى خمسين سطرًا، مع حساب ومركز تكلفة ومصدر ودليل. يحسب الخادم المدين والدائن بوحدات العملة الصغرى ويرفض الاختلاف والكسور الزائدة والأسس والأعداد السالبة. يراجع شخص آخر النسخة ويعتمدها قبل ترحيلها داخليًا. الترحيل يفحص صلاحية المعتمد الحالية، وسريان الحسابات والمركز والفترة. تثبت السطور والقرار والنسخة بعد التقديم؛ الإعادة تحفظ التاريخ وتستلزم اعتماد نسخة لاحقة.

العكس ينشئ مسودة مرتبطة بقيد مرحل، بمعد مختلف عن معد الأصل. تحمل المسودة سطور الأصل مع تبادل المدين والدائن، وتمر بالمراجعة والترحيل. يمنع إنشاء عكس ثانٍ للمصدر. الأستاذ وميزان المراجعة يستخرجان من قيود لها سجل ترحيل فعلي داخل هذه القاعدة، ولا يحتسبان المسودات أو الاعتماد وحده.

يمكن تحويل مستحق مشتريات مطابق إلى مسودة قيد واحدة، بحساب أصل أو تكلفة مدين والتزام دائن. يحافظ القيد على قيمة المستحق ومصدره. يظهر ترحيله المحلي في المالية من رابط القيد؛ سجل المشتريات الأصلي ثابت ويظل الدفع غير منفذ. لا توجد إشعارات دائنة أو تسوية مصرفية في هذه الحزمة.

## العقود

- GET /finance: الحسابات والمراكز والفترات والقيود والأستاذ وميزان المراجعة والمستحقات المأذونة وتاريخ ومصدر التقرير.
- POST /finance/accounts وcost_centers وperiods: إنشاء مرجع صريح. تعريف المرجع ثابت، مع تفعيل أو تعطيل الحساب والمركز، وإقفال الفترة بدليل.
- POST /finance/journals و/finance/from-payable: إنشاء بمفتاح تكرار؛ القراءة المعادة تفحص التصريح الحالي.
- POST /finance/journals/:id/:action: edit، submit، return، approve، reject، post، reverse. كل فعل يتطلب version ودليلًا. العكس يحتاج الفترة والتاريخ والسبب والدليل.
- POST /finance/:kind/:id/:action: activate، deactivate أوclose وفق نوع المرجع.

الدوال تعيد فحص مستخدم نشط وتصريح finance_grants مستقل لكل فعل ومدة ودور، وتطلب معاملة من المستدعي. admin لا يقرأ المال تلقائيًا. لا توجد واجهة لإضافة التصاريح المالية؛ يضيف expand-demo.mjs تصريحين لحسابين مصطنعين مسميين فقط، ولا يغير صلاحيات حسابات قائمة.

## حدود التغطية

الدليل محلي أحادي العملة، والفترات غير متداخلة. إقفال الفترة يمنع الترحيل لكنه لا ينفذ قائمة الإقفال والتسويات والاستحقاقات وتوقيع ملاكها في FIN-09. لا قوائم مالية مكتملة أو تخصيص قبض في FIN-03 أو أعمار ذمم في FIN-04 أو توقع سيولة في FIN-07 أو تكامل فوترة في FIN-08. التقرير يجمع جميع الفترات المرحلة دون مرشح تاريخ أو تصدير مأذون حتى الآن. لا حجز موازنة مشروع مشتركة أو تعريف هامش مؤسسي معتمد.

واجهة إنشاء القيد توفر ثلاثة سطور، وتحافظ على جميع سطور القيد الموجود عند تعديله؛ API يقبل حتى خمسين. يتطلب توسيع إنشاء السطور في الواجهة عملًا لاحقًا. الاختبارات في tests/finance.test.mjs وtests/operations-http.test.mjs، ونتيجة المجموعة النهائية تسجل في docs/testing/.
