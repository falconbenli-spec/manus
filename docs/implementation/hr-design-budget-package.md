# المخصصات

أُصلح عدد معاملات إدخال المخصص، ووُصلت وحدة budgets بالخادم والواجهة. منشئ المشروع المدير يمنح نطاق قراءة ماليًا محدد المدة لمستخدم مالي مصرح، ويمكنه سحبه. المخصص يرتبط بالمشروع ومركز التكلفة والعملة والفترة؛ يعدّه شخص ويعتمده شخص آخر.

ترسية الشراء تحتاج الآن ثلاثة عروض ومخصصًا معتمدًا ساريًا. الحجز والموافقة والتدقيق داخل معاملة واحدة؛ مجموع طلبين لا يتجاوز السقف. اعتماد الأمر يحول الحجز إلى التزام، والرفض يحرر الحجز دون حذف تاريخه. سحب نطاق معتمد المخصص يمنع الأمر اللاحق. خفض السقف لا يُعتمد إن أصبح أقل من الحجوزات والالتزامات. هذا ليس دفعًا أو محاسبة بنك أو بطاقة أسعار الموردين.
