# حزمة مستحقات العملاء والتحصيل المحلي

تنفذ الحزمة جزءًا من FIN-03 وFIN-04. يبدأ الاستحقاق من مخرج له قبول داخلي نهائي ومرتبط باتفاق ومشروع. تحفظ لقطة المصدر رقم العرض وبصمته وبند العقد ونسخة التسليم، وتمنع مطالبة ثانية للمخرج نفسه أو مبلغًا يتجاوز قيمة البند.

يعد صاحب تصريح `prepare` الاستحقاق، ويعتمده صاحب تصريح `approve` مختلف. تحفظ النسخة المقدمة والقرار كسجلات ثابتة. تسجيل القبض لا يعني وصولًا بنكيًا: يسجل مرجعًا ودليلًا في حالة معلقة، ثم يطابقه مخول مستقل. يمنع مجموع المقبوضات المعلقة والمؤكدة من تجاوز مبلغ الاستحقاق، ويمنع تكرار المرجع داخل الكيان.

تعرض القائمة الرصيد الداخلي وحالة العمر. النزاع المفتوح يظهر «متنازع عليه» بدل دمجه في المتأخرات. جداول النزاعات والوعود والتعديلات موجودة في الترحيل 012، لكن إنشاء النزاع وحله والوعود والعكس لم تصل إلى API والواجهة في هذه الحزمة.

هذه ليست فاتورة ضريبية أو إشعارًا بنكيًا أو تحصيلًا فعليًا. لا يوجد اتصال بفوترة رسمية أو بنك أو إرسال للعميل. لم يُنشأ قيد محاسبي تلقائي من الاستحقاق أو القبض؛ هذا يحتاج سياسة حسابات وفترات وقبول المالية.

التحقق محفوظ في `docs/testing/test-results-receivables-final-20260916.txt`، وفحص الشاشة في `docs/testing/receivables-browser-20260916.json`. تغطي الاختبارات مصدر الاستحقاق، الحد المالي، منع التكرار، فصل الإعداد عن الاعتماد، ثبات النسخ، تخصيص القبض، المطابقة المستقلة، الرصيد، وتصنيف النزاع. تبقى معايير FIN-03 وFIN-04 جزئية حتى تنفيذ الدفعات المقدمة والنزاعات والوعود والتعديلات والربط المحاسبي وقبول مالك الإجراء.
