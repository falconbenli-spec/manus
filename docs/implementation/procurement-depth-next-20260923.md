# تعميق المشتريات: الحزمة التالية

هذه مواصفات تنفيذ لاحقة، وليست وظائف منفذة في جلسة 23 سبتمبر. المرجع نسخة 3-6t-live عند 34e2027 مع فحص app/procurement.mjs وapp/payables.mjs.

## المشكلة المثبتة

الأمر يحمل كمية وسعر وحدة على مستوى الطلب. الاستلام والمطابقة يجمعان الكمية على الطلب كله. أمر الدفع يأخذ قيمة المستحق كاملة ويمنع وجود أمر قائم آخر للمستحق. لذلك لا يصح عرض شراء متعدد البنود أو دفعة جزئية كقدرة مكتملة.

## المسار المقترح

أولوية الحزمة التالية البنود والمطابقة؛ الدفعات الجزئية حزمة تالية مستقلة بعد تثبيت الأرصدة. لا نجمع تغيير نموذج الشراء والدفع كله في رقعة واحدة.

1. سطر شراء بمعرف ثابت ووصف ووحدة وكمية وسعر وعملة وتخصيص تكلفة.
2. الاستلام والفوترة والمطابقة تعود إلى معرف السطر والنسخة المعتمدة، لا ترتيب الصف أو الاسم.
3. حفظ لقطة البنود عند الاعتماد ومنع تعديلها؛ التعديل يستدعي نسخة ومسارًا صريحًا.
4. ترحيل محلي اختباري يحول الطلب القديم إلى سطر واحد مع حفظ المعرفات والأرقام والإثباتات.
5. توزيع التكلفة لا يغير مجموع الأمر ولا يضاعف الالتزام عند إنشاء الفاتورة.
6. فروق المطابقة تظهر مع مسؤول وحالة؛ مقدار السماح سياسة مطلوبة، فلا تُخترع نسبة.

## معايير قبول قابلة للاختبار

| الحالة | النتيجة المطلوبة |
| --- | --- |
| أمر بسطرين واستلام سطر واحد | يبقى الآخر غير مستلم، ولا تغطيه كمية السطر الأول |
| كمية فوق المتبقي في سطر | رفض ذري دون إنشاء أثر مالي أو استلام جزئي خفي |
| إعادة إرسال استلام بالمفتاح نفسه | نتيجة واحدة دون مضاعفة الكمية أو التدقيق |
| فاتورة صحيحة لسطر مستلم | إنشاء استحقاق مرة واحدة بعد المطابقة والصلاحية |
| فاتورة لسطر لم يستلم أو فرق بلا سياسة سماح | توقف واضح دون إنشاء مستحق قابل للدفع |
| تغيير بنود أمر معتمد | رفض التعديل المباشر والحفاظ على النسخة المعتمدة |
| صلاحية لمشروع آخر أو كيان آخر | رفض القراءة والتعديل والمطابقة والتصدير |
| طلبات قديمة ذات سطر واحد | مجموع المبالغ والكمية والحالات يبقى مطابقًا بعد الترحيل الاختباري |
| توزيع تكلفة | مجموع التخصيص يساوي القيمة المسموح توزيعها دون خطأ تقريب غير موثق |

المتطلبات الداعمة PRC-04/05/06 وFIN-05؛ لا تُبدل معايير قبولها الأصلية بهذه القائمة ولا تُعلن اكتمالها تلقائيًا. يلزم قبول المالية والمشتريات لمعنى التخصيص والسماح وفصل الاستلام عن الدفع.

## ترتيب التنفيذ

اختبار ترحيل ومطابقة يفشل على النموذج القديم، ثم نموذج البنود والمعاملات، ثم التكييف مع واجهة قائمة، ثم اختبار رحلة كاملة وصلاحيات وتكرار، ثم مطابقة الرصيد. استخدام خدمات مالية خارجية أو قاعدة إنتاج ليس ضمن الحزمة المحلية.
