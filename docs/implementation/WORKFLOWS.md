# مسارات WF01–WF10

هذه شروط المصدر محفوظة لاستكمالها. لا مسار من العشرة اجتاز قبولًا كاملًا؛ رحلة الطلب الداخلي والمشروع تدعم أجزاء من النواة فقط.

## WF01 — من فرصة إلى تحصيل

تأهيل ← عرض مسعر ← اعتماد هامش ← عقد ← مشروع ← موارد ومخرجات ← قبول العميل ← فاتورة صحيحة ← تحصيل ← تحليل هامش

مدير الحساب + PMO + المالية

لا التزام دون نطاق وميزانية؛ لا فوترة بلا استحقاق تعاقدي

تغيير نطاق / نزاع / دفعة مقدمة / عقد اشتراك

الحالة: منفذ جزئيًا من التأهيل إلى العرض والاتفاق والمشروع وقبول التسليم وتغيير النطاق؛ الفوترة والتحصيل وتحليل الهامش الكامل غير مكتملة.

## WF02 — إنتاج محتوى واعتماده

brief ← كتابة/تصميم ← تدقيق ← اعتماد داخلي ← عميل ← تعديلات ← اعتماد نسخة ← نشر/تسليم ← أرشفة

الإبداع + الحسابات

اعتماد مربوط بمعرف نسخة؛ عداد المراجعات والنطاق

رفض / حقوق منتهية / تعديل بعد الاعتماد

الحالة: منفذ جزئيًا: موجز ومخرج نصي بنسخ ومراجعة وحقوق وبيان تسليم وقبول داخلي؛ بوابة العميل والنشر والمرفقات الإعلامية غير مكتملة.

## WF03 — المؤثر من ترشيح إلى دفع

تأهيل ← قائمة قصيرة ← تفاوض ← حقوق وعقد ← brief ← اعتماد محتوى ← نشر ← إثبات ← فاتورة ← دفع

المؤثرون + المشتريات + المالية

لا دفع قبل قبول المخرج وتحقق بيانات البنك

حذف منشور / إلغاء / نشر مخالف / تأخر

الحالة: لم ينفذ المسار التجاري الكامل.

## WF04 — الشراء إلى الدفع

طلب ← تحقق مخصص ← عروض ← ترسية ← أمر شراء ← استلام ← مطابقة فاتورة ← موافقة دفع ← إثبات بنك

المشتريات + الطالب + المالية

مطابقة ثلاثية وفصل صلاحيات

شراء طارئ / استلام جزئي / اختلاف قيمة

الحالة: منفذ جزئيًا حتى مقارنة العروض وأمر الشراء والاستلام والمطابقة والمستحق والقيد المحلي؛ الحجز المشترك والدفع وإثبات البنك غير مكتملة.

## WF05 — الحضور إلى مسير الراتب

مصدر حضور ← تقويم وورديات ← استثناءات ← توضيح موظف ← اعتماد مدير ← مراجعة HR ← مدخل مسير

HR + المدير + الرواتب

نقص البصمة أو رد الموظف ليس خصمًا معتمدًا

مهمة / إجازة / عمل ميداني / نسيان تسجيل

الحالة: لم ينفذ المسار التجاري الكامل.

## WF06 — الانضمام والنقل والمغادرة

طلب معتمد ← عقد/تغيير ← تهيئة حساب وعهدة وصلاحيات ← تحقق جاهزية ← توثيق؛ عند المغادرة تسليم وإيقاف وصول وتسوية

HR + التقنية + المالية + المدير

ربط إجراء مؤرخ؛ إيقاف الوصول مستقل عن اكتمال المستحقات

تأخر مباشرة / نقل مدير / مغادرة فورية

الحالة: منفذ جزئيًا: احتياج وتقييم ومقترح وقبول داخلي وقائمة تهيئة؛ إنشاء الحساب والعهد والنقل والمغادرة والتسوية غير مكتملة.

## WF07 — التقييم السنوي

أهداف وأوزان ← متابعة ← ذاتي ← مدير ← معايرة ← اعتماد ← إبلاغ ← تظلم ← تطوير

HR + المديرون

لا قرار ترقية/جزاء آلي من استبانة أو AI

تغيير مدير / إجازة طويلة / قلة مدة التقييم

الحالة: لم ينفذ المسار التجاري الكامل.

## WF08 — صوت الموظف

إرسال آمن ← رقم مرجعي ← فرز مخول ← تحديد تعارض ← معالجة وأدلة ← رد ← إغلاق أو استئناف

مسؤول شكاوى مستقل

الحد الأدنى من الهوية؛ لا يطلع طرف الشكوى على الملف تلقائيًا

شكوى على المدير / خطر عاجل / طلب سرية

الحالة: لم ينفذ المسار التجاري الكامل.

## WF09 — الإطلاق والتغيير التقني

طلب ← أثر ومخاطر ← فرع كود ← مراجعة واختبارات ← قبول أعمال ← نشر مضبوط ← مراقبة ← رجوع عند الحاجة

مالك المنتج + التقنية + QA

لا أسرار في الكود؛ لا إنتاج دون اختبار وسجل إصدار

هجرة فاشلة / اختبار صلاحيات فاشل / تعطل خدمة

الحالة: لم ينفذ المسار التجاري الكامل.

## WF10 — التقرير التنفيذي المصدق

مصادر موثقة ← تحقق جودة ← احتساب بالمؤشرات المعتمدة ← مراجعة مالك ← لقطة ← نشر مقيد ← متابعة قرارات

مالك البيانات + الإدارة

عدم توفر المصدر يظهر كغياب بيانات لا صفرًا

تأخر مزامنة / تصحيح لاحق / مؤشرات متعارضة

الحالة: لم ينفذ المسار التجاري الكامل.
