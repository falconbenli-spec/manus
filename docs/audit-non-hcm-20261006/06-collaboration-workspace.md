## ما هو منفذ فعليًا

1. **عقد مساحة واضح ومقيد:** ترحيل 196 ينشئ مساحة واحدة لكل هدف، عضويات مؤرخة، قوائم ومهام وتعليقات وسجل نشاط؛ الترابط بالمستأجر موجود في المفاتيح الأجنبية الأساسية.
2. **وصول دفاعي:** `spaceById` يعيد 404 للمستخدم غير المؤهل أو العضوية المنتهية/المزالة؛ `collaborationActor` يطبق القدرات عند كل خدمة. الاختبارات تقصد إثبات غياب وصول admin الضمني وعزل المستأجر.
3. **تكامل مشروع/إدارة محدود ومناسب:** مساحة المشروع تقرأ مهام `tasks` الموجودة؛ مساحة الإدارة/المبادرة تستخدم `space_tasks`. طلبات المصدر المرتبطة تقرأ فقط ولا تتجاوز مسار الطلب الأصلي.
4. **نزاهة المحتوى:** مراجعات المستندات والملفات غير قابلة للتعديل أو الحذف بمحفزات SQL؛ الدليل يثبّت hash/نسخة الملف؛ المنشورات والحجب يحتفظان بالأثر والسبب.
5. **ضبط الإدخال:** تحقق نصوص وأطوال وتواريخ، قوائم مسموحة للأولوية/التكرار، version متفائل، وفحص توقيع المحتوى واسم الملف والحجم.
6. **API محكوم:** GET لا يعيد bytes الملف في لوحة الملفات، التنزيل يمر بالوصول وحالة الفحص وhash، والإنشاءات الرئيسية تمر بمفتاح idempotency وCSRF على مستوى الخادم.
7. **واجهة عربية RTL ومتنقلة:** أدوات المهام، البطاقات، الرسائل، المحادثة، الجدول، الملفات، check-ins، الأشخاص، والرؤى موجودة؛ اختبار الواجهة الحديث نجح 3/3 باستخدام Node 24.
8. **بحث مقيد:** ترحيل 199 يضيف أنواع مساحة العمل إلى البحث؛ اختبار المصدر يغطي منع ظهور عنوان المساحة بعد سحب العضوية وعدم فهرسة المحادثة/bytes الملف.

## المسارات والواجهة والبيانات

- **المسارات المقروءة:** `/api/work`, `/api/spaces`, ثم `/api/spaces/:id/{tasks,files,topics,chat,events,check-ins,people,activity,report}`؛ الحارس يستدعي خدمة العضوية في كل مورد.

## الخطوات التالية المقترحة

1. **إغلاق P0 للملفات:** وصل ماسح AV/خدمة scanning موثقة النتيجة، اجعل `clean` نتيجة موقعة/مرتبطة بالنسخة لا متغير بيئة، وأضف quarantine وعمليات retry ومراقبة؛ لا تفتح تنزيل الإنتاج قبله.
2. **أكمل حلقة العمل:** أنشئ inbox/notifications محلية للـ assignee، المشاركين، check-in المستحق، تحديث/تعليق/موعد؛ امنح المستخدم deep link محددًا ولا ترسل خارجيًا قبل سياسة القناة والموافقة.
3. **سد API–UI:** أضف الواجهات اللازمة أو أزل/أخف API غير المدعوم: CRUD القوائم، تعديل/تعليق/reopen المهمة، إدارة الأشخاص، موضوع/chat revision/redaction/convert-to-task، event cancellation/attendees، تاريخ وتنزيل/استبدال الملفات، revision/publish الوثائق، evidence من ملف ومستند.
4. **صحح التكرار والوقت:** نفّذ event occurrences أو غيّر المنتج إلى حدث مفرد؛ قيد إجابة check-in بـ`due_at <= now < closes_at`، واستبدل حساب الشهر بمنطق يثبت يوم الشهر الأخير، واختبر 29–31 ونهاية السنة والتشغيل المكرر.
5. **اجعل تحميل الواجهة حسب الأداة:** اجلب أساس المساحة والأداة المختارة فقط، مع التحميل المؤجل لبقية اللوحات؛ أضف تعامل جزئي graceful failure بدل فشل الشاشة كلها.
6. **اختبارات قبول وتشغيل:** أعد تشغيل الحزمة المركزة ثم `npm run check` و`npm run gate` بـ Node 24.21.0 في sandbox غير مزدحم، وسجل log/hash وتاريخ/commit. أضف E2E للواجهة، notification/inbox، scanner، calendar recurrence، check-in closure، وملكية/حدود تنزيل الملف.
7. **قرار منتج صريح:** اعتمد/ارفض سياسة الضيوف الخارجيين والعملاء، التكاملات الخارجية، object storage والاحتفاظ بالملفات، وسلوك التعليقات/المراجعات بعد سحب العضوية قبل إعلان المجال جاهزًا للإنتاج.
